5. Registration form

Fields: Full name, Work email and Organization (required); Area of interest — Strategy, Operations or Team Enablement (optional). The form uses noValidate and a validate() helper for consistent messaging: missing values produce field-level errors, and a malformed email produces "Enter a valid email address, for example name@company.com.".

Errors are visible next to the input, linked by aria-describedby, flagged with aria-invalid="true", and the first invalid control receives focus. Correcting a field clears its error immediately. A valid submit replaces the form with an aria-live="polite" status containing the exact supplied confirmation text and a "Send another request" reset button.

Local-only behaviour: values live in React state for the current browser session. There is no fetch, no localStorage, no analytics and no server or inbox integration. The word "recorded" refers only to this in-session state.
